GamePoint

A mobile sports community platform that helps users discover, create, and participate in local sports activities while connecting players with nearby venues and games.

View Documentation View on GitHub View demo on LinkedIn ↗
01 — Overview

Connecting players through local sports.

Finding people to play sports with can be difficult due to scheduling conflicts, limited players, or difficulty discovering suitable locations.

GamePoint was designed to provide a centralized platform where users can create sporting activities, discover available games, join other players, and find nearby venues.

The application combines a React Native mobile interface with a Spring Boot REST API backend and PostgreSQL database, creating a full-stack architecture for managing users, games, venues, and player participation.

Key features

Core functionality designed around discovering games, organizing players, and finding suitable sports venues.

01

Game Management

Users can create sports games with details such as sport category, venue, date, time, difficulty, and maximum player capacity.

02

Join Local Games

Players can browse available sporting activities and join games hosted by other members of the community.

03

Player Availability

Games track current players and maximum capacity, helping users understand whether a game still has available spaces.

04

Venue Discovery

Google Places API integration allows users to search for nearby venues and access information including addresses, ratings, and geographic coordinates.

05

Game Details

Each game provides important information including sport, venue, date, time, difficulty level, host, and player availability.

06

Host Management

Users who create games can manage their hosted activities, including cancelling games when necessary.

System architecture

GamePoint follows a client-server architecture where the React Native application communicates with the Spring Boot backend through REST APIs.

React Native Mobile Application
↓ REST API
Spring Boot Backend REST API
↓ JPA / Hibernate
PostgreSQL Relational Database

REST API

The backend provides REST endpoints for managing sporting games and player participation.

GET /api/games

Retrieve available games.

POST /api/games

Create a new sports game.

GET /api/games/{id}

Retrieve a specific game.

POST /api/games/{id}/join

Join an existing game.

DELETE /api/games/{gameId}?hostId={hostId}

Cancel a hosted game.
