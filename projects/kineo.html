Kineo

An AI-powered mobile travel planning application that helps users discover destinations, generate personalized travel plans, organize trips, and estimate travel budgets.

View documentation View on GitHub
01 — Overview

AI-assisted travel planning in one mobile application.

Planning a trip can often require users to search across multiple platforms for destinations, activities, locations, budgets, and itineraries.

Kineo aims to simplify this process by providing a centralized mobile application where users can discover destinations, generate personalized travel plans, organize trips, and receive AI-powered recommendations.

The application combines a React Native and Expo mobile interface with Firebase services, Google Maps and location services, and Google's Gemini API.

Key features

Kineo combines AI-powered travel planning, destination discovery, budget planning, location services, and personalized trip management into one mobile application.

AI-Powered Trip Planning

Uses Google's Gemini API to assist with travel planning, recommendations, destination discovery, and structured travel information.

Destination Discovery

Allows users to explore destinations, discover recommended places, search locations, and interact with travel-related information.

Trip Creation

Users can create personalized trips based on destination, travel dates, number of travelers, preferences, budget, and travel style.

Budget Planning

Provides different budget categories that can be used when generating and organizing personalized travel plans.

Location & Maps

Integrates Google location services for destination search, place discovery, maps, and geographic information.

Saved Trips & Places

Users can save generated trips, like destinations, manage saved places, and access their travel information.
