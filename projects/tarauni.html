TaraUni

A full-stack student transportation platform that helps university students create, discover, and join carpools while planning convenient transportation routes around campus.

View Presentation View on GitHub View demo on LinkedIn ↗
01 — Overview

Making university transportation easier.

Finding reliable transportation to university can be difficult due to limited public transportation options, scheduling conflicts, long walking distances, and unexpected delays.

TaraUni was designed as a centralized transportation platform where students can organize shared rides, discover available carpools, search for locations, and plan journeys using location-based services.

The application combines a React Native and Expo mobile interface with a Java Spring Boot REST API and PostgreSQL database. Google Maps, Google Places, and AI services are integrated to provide location and transportation functionality.

Key features

TaraUni combines carpooling, route planning, location services, and AI assistance into a single student-focused transportation platform.

01

Carpool Management

Students can create carpools with an origin, destination, travel date, time, passenger capacity, and price per passenger.

02

Discover & Join Carpools

Students can browse available carpools and join shared rides created by other students based on their transportation needs.

03

Route Planning

Google Maps integration provides route calculation, travel distance, estimated travel time, and map-based route visualization.

04

Location Services

Users can detect their current location, search for destinations, select pickup locations, and interact with locations through maps.

05

AI Transportation Assistant

An AI-powered assistant allows users to interact with transportation information using natural language and receive transportation-related assistance.

06

Student-focused Transportation

TaraUni brings carpooling and transportation planning together to help students make more convenient decisions when travelling to and from university.

System architecture

TaraUni follows a client-server architecture where the React Native application communicates with the Spring Boot backend through REST APIs.

React Native + Expo Mobile Application
↓ REST API
Spring Boot Backend REST API
↓ JPA / Hibernate
PostgreSQL Relational Database
